# hoshino-backend

To install dependencies:

```bash
bun install
```

install node-ytdlp-wrap

```bash
cd node_modules/node-ytdlp-wrap/lib
bun run install.js
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.3.11. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
